Find the clip, not just the video.

Type a scenario. It scores whether the venue is worth doing at all, then finds short, unwatermarked, mid-tail fail clips that fit the “first & last day” format.

This is a demo, not the live tool. Browser sandboxes block outbound API calls, so the clip results below were captured from real YouTube searches run locally. The venue scorer is live — type anything and it runs the real model in your browser.

The deployable version asks each person for their own API key, so running a search spends your quota and nobody else’s.

How it works

1 · Venue

Score the scenario before spending effort on it. A ridge model fitted on 41 of his uploads. Saturation hurts most; raw danger turns out not to matter at all.

2 · Search

YouTube Data API, two query variants, cached. Reddit next. No TikTok scraping — that’s the watermarked pool we’re avoiding.

3 · Rank

Views scored on a band, not a curve. A 60M-view brand clip is worse than a 100k amateur fail. Licensing agencies and trick showcases are penalised.

4 · Judge

Claude reads the four frames above each clip. Watermarks, genre match, funny-for-this-channel. Built and wired; needs an API key, so it hasn’t run on this demo.

5 · Assemble

Two-act packs. First day mild, last day chaos, ordered by escalation. Not built yet.

Rankings shown are the heuristic prefilter only — the Claude judge hasn’t run here. The venue model is directional, not predictive (leave-one-out ρ = 0.43): it filters duds rather than picking hits. Clip titles, channels and view counts are live YouTube data captured at export; every clip links back to its source.
